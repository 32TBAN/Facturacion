# Primeo Interface System

## Direction and feel

- admin demo con tono editorial compacto
- lectura profesional, sobria y utilitaria
- prioridad en reducir scroll y altura visual innecesaria
- identidad basada en una top bar compacta y dock movil iconizado

## Depth strategy

- bordes suaves
- superficies cercanas
- sin sombras dramaticas
- separacion por contraste leve y densidad controlada

## Spacing base unit

- base compacta de 4px a 10px
- escalas principales:
  - micro: 4px
  - control: 10px
  - bloque: 14px
  - seccion: 18px
  - mayor: 24px

## Key component patterns

- `Shell`: `toolbelt strip` superior con contexto breve, acciones compactas y dock movil inferior con iconos.
- `SectionHeading`: heading corto, descripcion de una o dos lineas maximo y menor protagonismo vertical.
- `MetricCard`: tarjetas bajas, valor claro, label pequeno y detalle corto.
- `Panel`: encabezado breve, grilla densa y contenido resumido antes que descriptivo.
- `Dashboard`: vista corta con menos bloques, listas recortadas y foco en lectura above the fold.
- `Login hero`: titulo con escala reducida y balance de linea para evitar bloques altos.
