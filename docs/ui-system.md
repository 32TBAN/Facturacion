# UI System

## Direccion

Interfaz administrativa con tono editorial moderno. La meta no es parecer un dashboard generico, sino un producto demo con identidad propia.

## Intento visual

- humano: reclutador o reviewer tecnico revisando un proyecto de portafolio
- tarea: recorrer modulos, entender jerarquia y detectar criterio de diseno
- sensacion: sobria, refinada, operativa

## Color world

- marfil de papel
- grafito
- azul petroleo
- verde contable
- rojo sello

## Firma

`Ledger rail`: una columna persistente que une navegacion, contexto del modulo, identidad del producto y acciones globales.

## Tipografia

- serif expresiva para titulos
- sans legible para interfaz
- composicion con alto contraste de jerarquia

## Profundidad

- bordes suaves
- superficies cercanas
- sin sombras dramaticas

## Componentes base

- `Shell`
- `SectionHeading`
- `MetricCard`
- `DataTable`
- `Panel`
- `Field`
- `Button`
- `Badge`

## Reglas

- el dato lidera la composicion
- los colores semanticamente fuertes se usan con moderacion
- las tablas son el centro del producto
- los paneles laterales reemplazan pantallas de detalle innecesarias
